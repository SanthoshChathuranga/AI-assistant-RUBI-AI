# Rubi AI Assistant

Rubi is a simple AI assistant built using **Python** and **Tkinter**.

## Features

* Text commands
* Voice commands
* Open calculator and other applications
* Search the web when it doesn't know something
* Simple Tkinter GUI
* Password protection

## Password

`2005`

## How to Run

```bash
pip install -r requirements.txt
python rubi.py
```
